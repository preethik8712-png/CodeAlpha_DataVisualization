# CodeAlpha_DataVisualization

Project Overview

This project focuses on visualizing the Titanic dataset using Python. Different charts and graphs were created to identify patterns and trends in the data.

Objectives

- Understand the dataset through visualizations
- Compare passenger survival patterns
- Analyze gender and passenger class
- Understand age and fare distributions
- Identify relationships between variables

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab

Visualizations Created

- Titanic Survival Count
- Survival by Gender
- Survival by Passenger Class
- Age Distribution
- Fare Distribution
- Age vs Fare

Key Insights

The visualizations help understand passenger survival patterns, age distribution, fare variation, and the relationship between different variables.

Project Files

- "CodeAlpha_DataVisualization.ipynb"
- "README.md"

Conclusion

Data visualization makes it easier to identify patterns and trends in the Titanic dataset. The charts provide a clear visual understanding of the data.
